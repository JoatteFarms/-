# 조아떼농원 퍼스널브랜딩 홈페이지

## 파일 구성
- `index.html`: 홈페이지 콘텐츠와 기본 구조
- `style.css`: 색상, 레이아웃, 반응형 디자인
- `script.js`: 모바일 메뉴, 연도 표시, 맨위 버튼 기능

## Windows에서 미리보기
1. ZIP 파일을 원하는 폴더에 압축 해제합니다.
2. `index.html` 파일을 더블클릭합니다.
3. Chrome 또는 Edge에서 홈페이지를 확인합니다.
4. 인터넷 연결이 필요할 수 있습니다. 현재 임시 사진과 웹폰트는 외부 서비스에서 불러옵니다.

## 반드시 수정할 내용
1. 메인 이미지와 섹션별 임시 이미지를 조아떼농원의 실제 사진으로 교체합니다.
2. 농부 소개 문구를 실제 경험과 생각에 맞게 다듬습니다.
3. `index.html`의 이메일 및 유튜브 안내 문구를 실제 연락처와 링크로 교체합니다.
4. 실제 인증 범위가 확인된 경우에만 인증 관련 표현을 추가합니다.
5. 공개 전 모든 메뉴, 링크, 모바일 화면을 테스트합니다.

## 사진 교체 방법
`index.html`에서 `<img src="...">`를 찾아 사진 주소를 바꿀 수 있습니다.
메인 배경과 생태논 배경은 `style.css`에서 `background: url("...")` 형태로 지정되어 있습니다.
자체 사진 파일을 사용하려면 예를 들어 `images/farmer.jpg`에 사진을 넣고 주소를 `images/farmer.jpg`로 변경합니다.

## 유튜브와 연락처
현재 예시는 연락처 영역을 안내용 텍스트로 표시합니다. 실제 이메일이나 채널 URL을 넣기 전에는 공개하지 마세요. 문의 양식의 서버 전송 기능은 포함되어 있지 않습니다.

## 공개하기
이 프로젝트는 정적 HTML/CSS/JavaScript 사이트입니다. HTTPS를 지원하는 정적 웹 호스팅에 세 파일을 업로드해 공개할 수 있습니다. 사용자 지정 도메인을 연결하려면 호스팅 업체의 도메인 설정을 따라야 합니다.
